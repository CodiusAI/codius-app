# Claude Code

Codius runs Claude Code through the official `claude` CLI using the Claude Agent SDK.

## Does Claude Code cost extra in Codius?

No. Claude Code usage in Codius counts against your normal Claude plan limits. It does not require a separate pool of Agent SDK credits.

You still need a Claude plan that includes Claude Code, and your plan's usual usage limits apply.

## Getting started

Install and sign in to the Claude Code CLI on the machine running Codius. Codius uses that existing installation and account when you start a Claude Code agent.

## Use Claude Code in the Codius terminal

Claude Code also works great inside the Codius terminal. If you prefer the standard CLI experience, open a terminal in your workspace and run `claude` as usual.

You can use the terminal from Codius's desktop, web, or mobile app while keeping access to your workspace, git changes, and other Codius tools.
