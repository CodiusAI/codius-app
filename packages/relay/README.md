# @codius.ai/relay

Transport and end-to-end-encryption helpers used to bridge Codius hosts and
clients.

## Stability

This package is public so Codius's published packages can share the relay
protocol. Its low-level API is not yet documented as a stable public SDK.

See the [Codius documentation](https://codius.ai/docs) for supported connection
and self-hosting workflows.
