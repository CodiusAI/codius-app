# @codius.ai/protocol

Shared Codius protocol schemas, codecs, and wire types.

## Stability

This package is public so Codius's published packages can depend on it cleanly.
It is not a stable public API yet.

Schemas, exports, wire helpers, and types may change or disappear in any release
without advance notice. Use it outside Codius at your own risk until the package
is explicitly documented as stable.

## Development

This package is maintained in the
[Codius App repository](https://github.com/CodiusAI/codius-app). See the
[Codius documentation](https://codius.ai/docs) for supported public workflows.
