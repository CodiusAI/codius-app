# @codius.ai/highlight

Syntax-highlighting utilities shared by Codius interfaces.

## Stability

This package is public so Codius's published packages can depend on a
consistent build artifact. Its API is not yet documented as a stable public
interface.

Source and contribution guidance live in the
[Codius App repository](https://github.com/CodiusAI/codius-app).
