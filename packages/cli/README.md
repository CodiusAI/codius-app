# @codius.ai/cli

The Codius CLI controls Codius hosts, coding agents, workspaces, worktrees,
schedules, terminals, and chats from a terminal.

After the package is released on npm:

```bash
npm install --global @codius.ai/cli@beta
codius --help
```

The CLI is the command-line companion to Codius App. Coding-agent runtimes
remain independently selectable inside Codius.

See the [Codius documentation](https://codius.ai/docs) for installation,
commands, and supported workflows.
